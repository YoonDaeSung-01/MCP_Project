## 1. 기존 요구와 조사 기준

조사 당시의 범위는 Markdown Wiki, 공통 Chat, 학습 활동, Task·Calendar, 채용준비와 문서 편집이었다. 현재 계획은 기초 Python 실행과 정답 없는 Algorithm 학습 도움이다. 실전 문제는 Programmers에서 풀고 오답노트는 보조 기능으로 사용한다. 현재 구현 범위는 Project Plan을 따른다.

추가 기능은 다음 불편을 해결하는지로 판단한다. 기록할 때 분류 때문에 멈추는가, 저장한 자료를 다시 찾는가, 공부하며 화면을 자주 바꾸는가, AI 답변의 근거를 확인하는가, 계획한 공부를 실제로 시작하는가, 중단한 작업을 다시 이어갈 수 있는가. 숙련도 자동 판정·거대 커리큘럼 생성은 기존 후속 범위를 유지한다.

## 2. 서비스 사례

아래 확인 기능은 공식 안내의 사실이며 적용 판단은 우리 프로젝트에 대한 제안이다. 제품별 페이지 링크는 7절에 모았다.

|---|---|---|---|
| Notion | 정형 문서 템플릿, 웹페이지 저장 | 개념·오답·공고 메모 템플릿, URL 자료함 | 높음 |
| Obsidian | 레이아웃 저장·전환, 명령 팔레트, 링크·북마크·일일 노트 | 학습/코딩/취업 화면 프리셋, 전역 찾기, 관련 문서 이동 | 높음 |
| Capacities | 종류별 객체와 속성, 일일 메모, 객체 연결 | 날짜별 임시 메모, 메모에서 실제 할 일로 전환 | 높음 |
| Heptabase | 여러 화이트보드에서 같은 카드를 참조, 시각적 카드 정리 | 여러 학습 공간에서 같은 메모를 참조; 캔버스는 후속 | 중간 |
| Readwise Reader | 나중에 읽기·선별 목록, 하이라이트·주석 | 이번에 읽을 자료와 전체 보관함 분리, 근거 포함 발췌 메모 | 높음 |
| RemNote | 자료와 노트 병렬 보기, PDF 주석, 메모·플래시카드 연결 | 자료+메모+질문 분할 화면, 선택 문장으로 학습 카드 생성 | 높음/후속 |
| Anki | 앞뒤 카드·답 입력·빈칸 카드 | 직접 선택한 개념의 복습 카드; 반복 스케줄 엔진은 후속 | 후속 |
| Todoist | 빠른 추가, 자연어 반복 날짜 설정 | 어디서든 할 일 추가, 해석한 날짜 미리보기; 반복 규칙은 후속 | 높음/후속 |
| TickTick | 캘린더·목록·필터·집중 타이머·위젯 | 집중 화면, 선택적 타이머, 좁은 화면 요약 보기 | 중간 |
| Sunsama | 하루 계획, 예상 작업 시간 합계, 가능 시간과 비교 | 사용자가 고른 오늘 할 일, 시간 부족 표시, 미완료 직접 재배치 | 높음 |
| Amplenote | 작업에서 원래 노트로 돌아가기, 캘린더에 작업 배치 | 공부 할 일 → 관련 문서/메모/단원 이동 | 높음 |
| LeetCode | 주제별 문제 묶음과 학습 계획 | 알고리즘별 문제 세트, 시도·힌트·사용자 오답 기록 | 높음 |
| roadmap.sh | 기술별 로드맵과 사용자 정의 로드맵 | 선행 개념과 공부 범위 표시, 기존 트랙의 사용자 편집 | 중간 |
| NotebookLM 계열의 현재 Gemini Notebook 도움말 | 선택한 자료를 문맥으로 사용, 인용에서 원문 이동, 답변을 노트로 저장 | 참조 자료 표시·원문 확인·답변 일부 저장 | 높음 |
| Teal | 공고 저장, 지원 단계·날짜·메모·체크리스트 | 관심→준비→지원→면접→결과의 수동 지원 보드, 공고별 준비 메모 | 높음 |

Google의 notebooklm 도움말 URL은 확인 시 gemininotebook 도움말로 연결된다. 여기서는 해당 페이지에서 확인한 자료 선택·인용·노트 저장 패턴만 활용하며 다른 앱/API의 동일 기능 제공을 뜻하지 않는다.

## 3. 기능 후보 전체 검토

분류: 기본 = 이미 정한 기능의 품질 요구, 우선 = 첫 실제 사용에 추천할 추가, 선택 = 기본 흐름 이후, 후속 = 별도 설계가 필요. 비용은 현재 구조 기준의 상대적 개발 부담이며 확정 일정은 아니다.

### A. 진입·탐색·개인화

| 후보 | 구체적 동작 | 분류/부담 |
|---|---|---|
| 오늘 화면 | 선택한 오늘 할 일·일정·가까운 마감·최근 메모를 모음 | 우선/중간 |
| 이어서 하기 | 마지막 단원·메모·자료 위치 복원. 자동 숙련도·진도 판정과 구분 | 우선/중간 |
| 전역 검색·명령 메뉴 | 문서·메모·할 일·공고를 종류별로 찾고 바로 열기/추가 | 우선/중간 |
| 즐겨찾기·최근 항목 | 자주 읽는 위키 절·메모·단원 접근 | 우선/낮음 |
| 목적별 화면 저장 | 공부·코딩·취업 배치, 기본 배치 복원; 내용은 삭제하지 않음 | 우선/중간 |
| 기본 화면·빈 화면 안내 | 설정을 먼저 요구하지 않고 예시 메모와 추가 버튼 제공 | 기본/낮음 |
| 읽기 옵션 | 글자 크기·줄 간격·밝기 설정, 키보드 포커스, 작은 화면 대응 | 기본/중간 |

| URL 자료함 | URL·제목·확인 시각·저장 이유·단원 연결; 중복 URL 안내 | 우선/중간 |

## 4. 우선 적용할 묶음

기본 저장·복구·드래그 요청을 먼저 완성하고 다음 기능을 추천한다. 자동 구현 확정 목록이 아니라 조사 후 우선순위다.

1. 다시 시작하기: 오늘 화면 + 이어서 하기 + 즐겨찾기.
2. 기록을 놓치지 않기: 빠른 기록 + URL 자료함 + 메모 템플릿.
3. 공부 흐름 유지하기: 분할 화면 + 선택 자료 질문 + 근거 열기 + 답변 일부 메모.
4. 기록을 행동으로 옮기기: 메모→할 일 + 원문 연결 + 공부 시작 + 일정 배치.
5. 계획을 현실에 맞추기: 시간 합계 + 충돌 안내 + 미완료 직접 재배치.
6. 목적별 작업 환경: 기본 프리셋 세 개 + 사용자 배치 저장/복원.
7. 취업준비 마무리: 공고별 수동 단계 + 준비 메모/체크리스트 + 공부 연결.

우선순위가 높더라도 모든 것을 한 단계에서 만들지는 않는다. 첫 단원과 직접 관리 기능에 필요한 최소 동작으로 나누고 실제 사용에서 추가한다. 목록/폼부터 만들 수 있는 기능에 AI 호출·새 Agent·새 MCP 서버를 추가하지 않는다.

## 5. 화면 전략과 사례 흐름

첫 화면은 사용자가 기본값을 고를 수 있다. 오늘 또는 마지막 작업을 열고 공통 채팅은 접어둘 수 있다. 빈 화면을 직접 꾸며야만 공부를 시작할 수 있게 하지 않는다. 공부/코딩/취업 프리셋을 제공하고 사용자가 배치와 보이는 위젯을 바꾼다.

예: URL 저장 → 임시 보관함 → AI·백엔드 단원에 연결 → 자료를 읽으며 발췌·질문 → 답변 일부를 근거와 함께 메모 → 구현할 내용을 할 일로 전환 → 가능한 시간에 배치 → 다음 접속에서 작업·자료·메모를 함께 열기. 별도 자동 진도 엔진 없이 이어서 공부할 수 있다.

## 6. 구조와 개발 영향

새 메모 저장에는 Note Service, 자료함에는 Reference Service를 둔다. 기존 Task/Calendar/Job Service와 공통 ID로 연결한다. 학습 트랙·단원·작업의 관계를 조회할 수 있어야 한다. 사용자 작성 문서와 기존 읽기 전용 위키를 구분한다.

워크스페이스 프리셋은 레이아웃·보이는 패널 설정을 저장하며 메모 본문을 복제하지 않는다. 전역 찾기는 현재 규모에서 SQLite 검색 + 기존 위키 검색 결과를 종류별로 묶는 것부터 검증하고 새 벡터 DB를 선행 도입하지 않는다. 문서 위치는 문서 ID·절/블록 ID를 우선 사용하고 변경된 원문은 정확한 복원 실패를 표시한다.

메모는 AI Memory와 다르다. 선택된 메모와 사용자가 요청한 자료만 문맥에 포함하고, 수정은 기존 Harness·도구 검증·공통 Service를 거친다. 직접 CRUD·레이아웃·시간 합계·즐겨찾기·템플릿에 모델 호출은 필수가 아니다.

로컬 브라우저 앱의 타이머는 숨겨진 탭에서 지연될 수 있으므로 저장된 시작·종료 시각으로 남은 시간을 계산한다. 앱 종료·PC 절전 중 알림이 보장되는 것처럼 안내하지 않는다. 상시 리마인더·확장 프로그램·외부 동기화·무한 캔버스·자동 코드 실행은 각각 별도 설계를 요구한다.

확인 기준: URL 한 번 저장→두 곳에서 참조해도 중복 없음, 메모에서 만든 작업이 양쪽에서 같은 상태, 학습 단원과 마지막 작성 내용 복원, 시간 미정 작업을 포함한 합계 표시, 공고 지원 상태는 사용자 동작으로만 변경, 질문에 첨부한 자료를 해제하면 해당 내용 제외.
